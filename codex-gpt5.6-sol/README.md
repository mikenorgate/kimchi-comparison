# Tahoe Web Desktop

A dependency-free, interactive macOS Tahoe-inspired desktop experience.

Run it with any static file server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

Included interactions: draggable/minimizable/maximizable windows, application menus, Finder, Safari, Messages, Mail, Maps, Photos, FaceTime, Calendar, Notes, Music, System Settings, Downloads, Trash, Spotlight, Control Center, Notification Center, Stage Manager, keyboard shortcuts, widgets, and desktop files.
